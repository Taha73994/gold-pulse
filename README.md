# نبض الذهب — Gold Pulse

تطبيق عربي/إنجليزي لمتابعة أسعار الذهب وتحليلها للمستثمر العراقي، مع توقعات احتمالية، محلات ذهب، إعلانات مدفوعة، تحويل عملات، وتنبيهات لحظية.

**المطوّر والمالك:** Taha Ali — © 2026 جميع الحقوق محفوظة.

**النسخة المباشرة:** <https://gold-pulse-iota.vercel.app>
**مستودع الكود:** <https://github.com/Taha73994/gold-pulse>

---

## 1. المكوّنات

| الجزء | التقنية | المسار |
|---|---|---|
| الخادم | Python + FastAPI + SQLAlchemy + SQLite | `backend/` |
| التطبيق | Flutter (Android / iOS / Web / PWA) | `flutter/gold_pulse_app/` |
| الشعار والأيقونات | Pillow | `tools/make_logo.py` |
| البيانات | `data/gold_pulse.db` + `data/uploads/` | — |

الخادم يعمل على المنفذ **8010**، والنسخة الويب على **8020**.

## 2. التشغيل السريع

### أ) الخادم

```bash
cd gold_pulse
pip install -r requirements.txt
python run.py
# أو:
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8010
```

- واجهة التحقق: <http://127.0.0.1:8010/docs>
- للوصول من الهاتف على نفس الشبكة استخدم `--host 0.0.0.0` وافتح منفذ 8010 في جدار الحماية.

### ب) تطبيق الويب

```bash
cd flutter/gold_pulse_app
flutter pub get
flutter build web --release
# ثم قدّم مجلد build/web:
python -m http.server 8020 --directory build/web --bind 0.0.0.0
```

افتح <http://127.0.0.1:8020>. التطبيق **PWA قابل للتثبيت** على الحاسبة والهاتف.

### ج) تطبيق أندرويد (APK)

```powershell
$env:JAVA_HOME="C:\Android\jdk17"
$env:ANDROID_HOME="C:\Android\sdk"
flutter build apk --release --dart-define=API_BASE=http://<عنوان-الخادم>:8010
```

الناتج: `build/app/outputs/flutter-apk/app-release.apk`.

> غيّر `API_BASE` إلى عنوان IP للحاسبة التي يشغّل عليها الخادم، أو اتركه فارغاً
> ثم اضبط الخادم من داخل التطبيق: **الإعدادات ← عنوان الخادم**.

### د) آيفون (iOS)

بناء IPA يحتاج macOS + Xcode:

```bash
flutter build ios --release
# ثم Archive من Xcode أو:
flutter build ipa --release
```

مشروع iOS جاهز في `ios/`. كبديل فوري على الآيفون: افتح نسخة الويب في Safari
ثم **مشاركة ← إضافة إلى الشاشة الرئيسية** (تعمل كتطبيق كامل الشاشة).

### هـ) ويندوز (PC)

نسخة الويب تُثبَّت كتطبيق من Chrome/Edge: أيقونة **تثبيت** في شريط العنوان.
لبناء تطبيق ويندوز أصلي يلزم تثبيت **Visual Studio + C++ workload** ثم:

```bash
flutter create --platforms=windows .
flutter build windows --release
```

## 2.5 النشر على الإنترنت (استخدام من أي مكان)

التطبيق منشور ويعمل من أي مكان في العالم بدون الحاجة لتشغيل الحاسبة:

| الجزء | الخدمة | الرابط |
|---|---|---|
| التطبيق + الـ API | Vercel Hobby (مجاني، بدون بطاقة) | <https://gold-pulse-iota.vercel.app> |
| قاعدة البيانات | Neon PostgreSQL (مجاني) | — |

- ملف `pyproject.toml` يحدّد نقطة الدخول `backend.main:app` والاعتماديات.
- كل `push` إلى `main` يُنشر تلقائياً على Vercel.
- الصور المرفوعة تُحفظ في جدول `media_files` وتُقدَّم من `/api/media/{name}` فتبقى بعد إعادة النشر.

👉 التفاصيل الكاملة والمتغيرات والنسخ الاحتياطي في **[DEPLOY.md](DEPLOY.md)**.

لإعادة بناء APK يشير إلى السحابة:

```powershell
cd flutter\gold_pulse_app
flutter build apk --release --dart-define=API_BASE=https://gold-pulse-iota.vercel.app
```

> متغيرات البيئة المدعومة: `GOLD_ADMIN_PIN`، `GOLD_DATA_DIR`، `DATABASE_URL`
> (PostgreSQL)، `PORT`، `GOLD_PRICE_ALERT_PCT`، `GOLD_PRICE_ALERT_MINUTES`.

## 3. الميزات

- **أسعار لحظية**: أونصة بالدولار + عيارات 24/22/21/18 بالدينار، تحديث تلقائي كل 20 ثانية ومؤشر «مباشر · قبل X ث».
- **إشارة قرار واضحة**: شراء / تجميع / انتظار / تخفيف / بيع، مع «ماذا أفعل الآن؟» وخطوات ووقف وإبطال.
- **تحليل**: فني (اتجاه، متوسطات، RSI، MACD، زخم) + ماكرو (الدولار، عوائد السندات، VIX، S&P) + معنويات الأخبار.
- **توقعات احتمالية** لمونت كارلو (2/5/7 جلسات) بنطاقات 10–90%.
- **تنبيهات**: تغيّر الإشارة + **ارتفاع/انخفاض سعر الأونصة** بنسبة تتجاوز الحد، مع كتم تكرار.
- **حاسبة ذهب**: الوزن، العيار، المصنعية، العمولة، هامش التاجر، وسعر إعادة البيع.
- **دليل المحلات**: صورة، هاتف، واتساب، خريطة، وصف، أوقات العمل، شارة «موثّق».
- **إعلانات مدفوعة**: باقات، تمييز، مشاهدات ونقرات.
- **محوّل عملات**: USD, IQD, TOM, TRY, SYP, LBP, EUR, GBP, AED, SAR, KWD, JOD, EGP.
- **عربي RTL + إنجليزي**، وضع ليلي/نهاري، شعار وهوية بصرية خاصة.
- **عدّاد مستخدمين حقيقي** من نبضات الأجهزة.

## 4. لوحة المالك (خاصة)

لوحة المالك **لا تظهر للمستخدم العادي** إطلاقاً:

- الدخول: **ضغط مطوّل على شعار التطبيق** في الأعلى ← إدخال رمز المالك.
- الرمز الحالي على السحابة: `GoldPulse@2026` (يُضبط عبر `GOLD_ADMIN_PIN`).
- الرمز المحلي للتطوير: `taha2026`.
- بعد الدخول تظهر أيقونة «لوحة المالك» في شاشة «المزيد» وأزرار الإضافة.

### ما يمكن للمالك فعله

- إضافة/تعديل/حذف المحلات والإعلانات.
- **أي محل يضيفه المالك يصبح «موثّقاً» تلقائياً** (يمكن إلغاء الخيار يدوياً).
- ضبط **بيانات التواصل**: الاسم، الهاتف، واتساب، تلكرام، البريد.
- رؤية الإحصائيات الكاملة: المستخدمون، المنصات، اللغات، النسخ، مشاهدات الإعلانات، الإيراد التقديري.

### الخصوصية والإحصاءات

| البيانات | من يراها |
|---|---|
| عدد المستخدمين الكلي + المتصلون الآن | الجميع |
| نشط اليوم/الأسبوع + المنصات + اللغات + النسخ | المالك فقط |
| أرقام لوحة التحكم والإيرادات | المالك فقط |

### بيانات التواصل

حقول التواصل تُحفظ في قاعدة البيانات وتظهر للمستخدم **فقط إذا عُبّئت**:
إذا أضفت الهاتف والتلكرام فقط، يظهر زرّان فقط ولا يظهر واتساب ولا بريد.

## 5. مصادر البيانات والمنهجية

- الأسعار: Yahoo Finance — `GC=F` (الذهب)، `DX-Y.NYB` (الدولار)، `^TNX` (العائد)، `^GSPC`، `^VIX`.
- الصرف: `open.er-api.com` (USD/IQD وغيره).
- الأخبار: Google News RSS مع تحليل معنويات بسيط.
- الإشارة: تجميع مرجّح للمكوّنات ← درجة −100..+100:
  - `≥ 35` شراء، `≥ 12` تجميع، `> −12` انتظار، `> −35` تخفيف، غير ذلك بيع.
- التوقعات: محاكاة مونت كارلو (1600 مسار) على التقلب التاريخي، وتُعرض كاحتمالات لا كضمانات.

### حدود معروفة

- سعر الدينار تقديري من سعر الصرف المعلن وقد يختلف عن سوق المحلات.
- التوقعات احتمالية وليست نصيحة استثمارية.
- التنبيهات داخل التطبيق أثناء فتحه؛ إشعارات النظام عند الإغلاق تحتاج FCM/APNs.
- بيانات المحلات والإعلانات الأولية تجريبية (seed) ويمكن تعديلها من لوحة المالك.

**إخلاء مسؤولية:** هذا التطبيق أداة دعم قرار ولا يُعدّ نصيحة استثمارية. تحقّق دائماً من الأسعار لدى تاجر موثوق قبل الشراء أو البيع.
